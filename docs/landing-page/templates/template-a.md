# Template A — Recruiter/Collaborator focus

## Structure
1. One-line value proposition
2. 3 impact bullets (problem solved, outcome, stack)
3. Curated featured projects (strategic)
4. Recent updates (freshness)
5. Contact CTA by collaboration type

## Strengths
- High clarity and fast scan speed.
- Strong conversion for hiring/collab traffic.

## Tradeoffs
- Less deep technical detail for builder audiences.
