# Feature taxonomy matrix

Use this matrix to compare template variants quickly.

| Axis | Option 1 | Option 2 | Option 3 |
|---|---|---|---|
| Hero style | Minimal | Narrative | Metric-led |
| Project section style | Static curated cards | Auto-updated list | Hybrid curated + dynamic |
| Proof signals | Stars/activity | Case outcomes | Shipped artifacts/testimonials |
| CTA style | Collaborate | Hiring | OSS contributions/newsletter |

## Strengths / shortcomings lens
- **Minimal hero**: fast scan; weaker differentiation.
- **Narrative hero**: stronger personality; slower scan.
- **Metric-led hero**: high credibility; can feel impersonal.
- **Static curated cards**: strategic focus; higher manual upkeep.
- **Auto list**: fresh and cheap; can hide best work.
- **Hybrid**: balanced; needs good automation discipline.
